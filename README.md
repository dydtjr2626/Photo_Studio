# Photo Studio

브라우저에서 바로 쓰는 **이미지 카드 편집기**입니다. 사진을 올리고, 보정·자르기·그리기를 하고, 문구·도형·스티커를 얹어 1:1 · 4:5 · 9:16 · 자유형 카드로 저장합니다.
설치·빌드·외부 라이브러리 없이 HTML/CSS/JS 만으로 동작합니다.

## 실행

```
node server.js
```

브라우저에서 <http://localhost:8000> 을 엽니다. (`server.js` 는 이 폴더의 `.html .js .css .jpg .png` 만 제공하는 정적 서버입니다.)

## 주요 기능

| 분류 | 기능 |
|---|---|
| 사진 | 불러오기(PNG·JPEG·SVG·PSD)·드래그 앤 드롭·Ctrl+V 붙여넣기, 자르기, 회전·반전, 그리기/지우개, 배경 지우기(색·영역), 터치 보정(밀기·부풀리기·오므리기), 투명도 |
| 보정 | 밝기·대비·채도·따뜻함·흐림·색조·곡선(어두운 영역/중간톤/밝은 영역), 프리셋, 전체 보정 |
| 문구 | 글꼴 10종(웹폰트), 굵게·기울임·밑줄·취소선, 정렬, 자간·행간, 그림자·외곽선·그라디언트, 글자 배경, HEX·스포이트·브랜드 색 |
| 도형·스티커 | 도형 8종, 이모지 스티커 약 360개 |
| 합성 | 혼합 모드 15종, 모양으로 자르기(원·하트·별 등), 레이어 목록(순서·잠금·삭제), 잠금 |
| 배치 | 정렬 6종, 수치 입력, 다중 선택(Shift/Ctrl+클릭·범위 선택), 간격 같게, 스마트 가이드, 안내선 |
| 카드 | 여러 장 카드, 화면비 변경 시 **자동 재배치**, 자동저장(브라우저)·복구 |
| 저장 | PNG · 투명 PNG · JPEG(품질 선택) · 1x/2x/3x · 모든 카드 ZIP · **모든 화면비 ZIP** · PDF · SVG · PSD(레이어별) · 프로젝트 파일(.json) · 템플릿 JSON |

미리보기와 저장은 **같은 렌더 함수**를 쓰고, 저장한 파일을 다시 읽어 미리보기와 픽셀 단위로 비교합니다(기본 저장). 불러온 사진은 다시 인코딩되어 EXIF·GPS 등 메타데이터가 제거됩니다.

## 단축키 (일부)

`Ctrl+Z` 되돌리기 · `Ctrl+Y` 다시 실행 · `Ctrl+J` 복제 · `Ctrl+C/V` 복사·붙여넣기 · `Ctrl+A` 모두 선택 · `Ctrl+S` PNG · `Ctrl+Shift+S` JPEG · `Ctrl+O` 사진 불러오기 · `V` 이동 · `C` 자르기 · `B` 펜 · `E` 지우개 · `T` 문구 · 방향키 미세 이동 · `?` 전체 단축키 안내

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조(ID 를 스크립트가 직접 참조) |
| `app.js` | 핵심 로직: 렌더 엔진, 상태, 사진 도구, 문구·도형, 저장, 템플릿 |
| `extras.js` | 글자 효과·색·레이어 목록·붙여넣기 |
| `project.js` | 여러 장 카드, 자동저장(IndexedDB), 프로젝트 파일, ZIP |
| `pro.js` | 자동 리사이즈, PDF·SVG·PSD 입출력, 모든 화면비 저장 |
| `multi.js` | 다중 선택, 정렬·간격 맞추기 |
| `align.js` · `zoom.js` · `ux.js` · `a11y.js` · `layout.js` | 정렬·가이드 / 줌 / 안내·단축키 / 접근성 / 컨트롤 재배치 |
| `style.css` · `layout.css` · `features.css` · `a11y.css` | 디자인 토큰·스킨 / 레이아웃 / 부가 기능 / 접근성 |
| `server.js` | 정적 서버 |
| `CLAUDE.md` | 구조·설계 결정·주의점 상세 기록 |
| `확인방법.md` · `출처기록표.md` | 점검 방법 / 이미지 출처 기록 |

## 알려진 한계

- 웹폰트는 Google Fonts 에서 받아 오므로 인터넷이 없으면 설치된 글꼴로 대체됩니다.
- 자동저장은 사용 중인 브라우저에만 저장됩니다. 다른 PC 로 옮기려면 프로젝트 파일(.json)로 저장하세요.
- PSD 가져오기는 8비트 RGB·raw/RLE 만 지원하며 문구·스마트 오브젝트·조정 레이어·효과는 이미지로만 들어옵니다. PSD 저장은 Pillow 로 검증했고 Photoshop 에서는 확인하지 못했습니다.
- 사진 보정(필터)은 Safari 에서 동작하지 않습니다.
- 모바일·터치는 브라우저 에뮬레이션으로만 확인했고 실기기 검증은 하지 못했습니다.
